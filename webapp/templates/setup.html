API 연동 설정

여기서 입력한 값은 전부 이 컴퓨터의 로컬 파일(data/app.db)에만 저장됩니다. 외부 서버로 전송되지 않습니다.

1. Threads (Meta)
1) developers.facebook.com 에서 앱 생성 → "Access the Threads API" 유즈케이스 추가 2) 이용 사례 → Threads API 액세스 → 설정 화면에서 App ID/Secret 확인 3) ⚠️ Redirect URI 저장이 안 되면, 먼저 "앱 설정 → 기본 설정 → 앱 도메인"에 아무 도메인이나(예: example.com) 등록해두고 다시 시도하세요 (Meta 콘솔의 알려진 이슈) 4) "사용자 토큰 생성기" 섹션에서 본인 계정을 Threads 테스터로 추가 → 초대 수락 → 토큰 생성 → 아래에 붙여넣기
2. Claude API
console.anthropic.com → API Keys → Create Key
3. 네이버 커머스API (상품홍보 모드에서 상품 목록 가져올 때 필요)
apicenter.commerce.naver.com → 로그인 → "내 스토어 어플리케이션" 발급 → Client ID/Secret 확인 (위임 인증이 아니라 본인 명의로 직접 발급받아야 합니다. 리뷰 모드만 쓸 거면 비워둬도 됩니다.)
4. 카카오톡 "나에게 보내기" 알림 (선택)
1) developers.kakao.com → 애플리케이션 추가 → REST API 키 확인 2) 제품 설정 → 카카오 로그인 활성화, Redirect URI 등록 (아래 기본값을 그대로 등록해도 됩니다 — Threads 설정 때 만든 GitHub Pages 페이지를 재사용합니다) 3) 제품 설정 → 카카오 로그인 → 동의항목에서 "카카오톡 메시지 전송(talk_message)"을 사용 설정 4) Client Secret 발급 후 아래에 입력하고 저장 → "카카오 인증 시작하기" 클릭
